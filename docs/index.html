playtestproxy-fill

Any deck → print-ready images for tcgplaytest.com

Accepts MTG Arena exports, MTGO .dek XML, ManaBox / generic CSV with Name + Quantity columns, copy/paste from any deck builder, plain "N Card Name" lines. Set codes / collector numbers in parens are optional. Sideboard / Maybeboard sections follow the option below; Tokens / Companion sections are always skipped (use the token options for tokens).

Options
Default back for non-DFC cards (optional override)

Then open tcgplaytest.com → Start Your Design, extract the ZIP, and drag fronts/ into the Fronts uploader on Step 1. Choose "No Bleed" — tcgplaytest applies the print-bleed expansion server-side. Then click Next, scroll to Sequential Backs, and drag backs/. The slot numbers in filenames keep DFC face-2 art aligned with their fronts. (If you didn't pair backs, the ZIP only has fronts.)

    How it works

    1. Fetches the deck from Archidekt / Moxfield (JSON), Scryfall / Deckbox / TappedOut / EDHREC (text exports). The deck-builder APIs are locked to their own origins so the request is routed through a public CORS proxy where direct fetch fails.
    2. For each card, pulls the exact printing's PNG from Scryfall — Secret Lair / alt-art selections come through faithfully.
    3. Bundles the unmodified Scryfall PNGs into a ZIP for you to download.

    Source: github.com/babyhuey/playtestproxy-fill — also includes a Python CLI + Playwright auto-uploader.
