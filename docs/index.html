playtestproxy-fill

Any deck → print-ready images for tcgplaytest.com

Accepts MTG Arena exports, MTGO .dek XML, ManaBox / generic CSV with Name + Quantity columns, copy/paste from any deck builder, plain "N Card Name" lines (the leading N is optional — bare card names count as one copy each). Set codes / collector numbers in parens are optional. Sideboard / Maybeboard sections follow the option below; Tokens / Companion sections are always skipped (use the token options for tokens).

    How it works

    1. Fetches the deck from Archidekt / Moxfield (JSON), Scryfall / Deckbox / TappedOut / EDHREC (text exports). The deck-builder APIs are locked to their own origins so the request is routed through a public CORS proxy where direct fetch fails.
    2. For each card, pulls the exact printing's PNG from Scryfall — Secret Lair / alt-art selections come through faithfully.
    3. Bundles the unmodified Scryfall PNGs into a ZIP for you to download.

    Source: github.com/babyhuey/playtestproxy-fill — also includes a Python CLI + Playwright auto-uploader.

    Deck-builder API traffic (Archidekt, Moxfield, Deckbox, TappedOut, EDHREC) is routed through corsproxy.io — that operator can read the requests.
