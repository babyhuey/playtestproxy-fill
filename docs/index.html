playtestproxy-fill

Archidekt deck → print-ready images for tcgplaytest.com

Options

Then open tcgplaytest.com → Start Your Design, extract the ZIP, and drag the images into the Fronts uploader. When the bleed modal appears choose "3mm Bleed added".

Failures

    How it works

    1. Fetches the deck JSON from Archidekt's API (via a public CORS proxy).
    2. For each card, pulls the exact printing's PNG from Scryfall — Secret Lair / alt-art selections come through faithfully.
    3. Pads each image with bleed using a Canvas (edge-replicated).
    4. Bundles everything into a ZIP for you to download.

    Source: github.com/babyhuey/playtestproxy-fill — also includes a Python CLI + Playwright auto-uploader.

    No data leaves your browser except API requests to Archidekt & Scryfall.
